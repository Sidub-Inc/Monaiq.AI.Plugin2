# Gate Prompt Patterns

Use short, host-native prompts. Avoid open-ended checkpoint questions unless the decision is genuinely undefined.

## Standard Approval

- Approve
- Revise
- Stop

## Workflow Control

- Continue
- Pause
- Escalate

## Binary Choice

- Yes
- No

## Strategy Choice

- Option A
- Option B
- Let Monaiq decide from evidence

Each prompt must include the intended change, user/business impact, affected entities/files, risk summary, and validation plan.
